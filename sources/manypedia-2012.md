# Manypedia: Comparing language points of view of Wikipedia communities

| | |
|---|---|
| **Authors** | Paolo Massa, Federico Scrinzi |
| **Venue** | WikiSym 2012 |
| **ACM** | https://dl.acm.org/doi/10.1145/2462932.2462960 |

## What it is

Web tool for **side-by-side** comparison of the same topic in two language editions, often with automatic translation into a common language, plus simple similarity / linking stats.

## Method (sketch)

- Pick article pair via interlanguage / Wikidata-style links.
- Present parallel reading + automatic translation.
- Surface community “point of view” differences qualitatively.

## Findings / contribution

Popular demonstration that cross-lingual POV is legible to non-specialists without full Omnipedia-scale UI.

## Relation to WikiDrift

Same cell as Omnipedia: **external-reference prototype**, snapshot form. WikiDrift’s L5 is automated, multi-layer (framing + facts + sources), and tied to temporal pivots rather than only “today’s two pages.”
