# A Comparative Study of Reference Reliability in Multiple Language Editions of Wikipedia

| | |
|---|---|
| **Authors** | Aitolkyn Baigutanova, Diego Saez-Trumper, Miriam Redi, Meeyoung Cha, Pablo Aragón |
| **Venue** | CIKM 2023 |
| **arXiv** | https://arxiv.org/abs/2309.00196 |

## What it is

Large-scale study of **citation reliability labels** across language editions, using English Wikipedia’s perennial sources list and related reliability judgments as a scaffold.

## Method (sketch)

- Analyze millions of articles / citations across languages.
- Map domains against reliability labels; compare presence of “untrustworthy” sources across editions.
- Case studies (Chinese, Russian, Swedish) for cultural discrepancy.

## Findings

- Domains labeled untrustworthy in English still appear in other languages (especially sources tailored to smaller communities).
- Non-authoritative sources on an English page tend to **persist** on other-language versions of the same page.
- Global coordination of “reliable source” norms is incomplete.

## Relation to WikiDrift

Supports **L5 #3b (citation composition)** as a meaningful signal: sourcing differs by edition and can be measured. WikiDrift’s choice is **not** to import reliability ratings into the product (rating is a contested judgment); instead show from→to domain mix across a pivot and let the reader decide.
